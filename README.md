**项目理念**：紫微斗数是中国传统命理学的瑰宝，倪海厦老师在《天纪》中系统梳理了正宗的紫微斗数体系。我们希望通过技术手段让更多人接触和学习这门学问。开源排盘算法和知识库，是因为我们相信：**算法是公开的传统智慧，不应该被锁在围墙里**。真正的价值在于解读的深度、用户体验的打磨、以及持续运营的积累。

**项目信息**：基于**倪海厦《天纪》**教学体系的紫微斗数排盘与修行平台，包含完整排盘算法、四化系统、格局知识库、古籍原文数据、AI解读、Web3钱包登录、加密货币充值、积分体系、每日修行打卡、修持祈愿、管理后台等功能。在线体验：[metisziwei.com](https://metisziwei.com/?from=gh-readme)

## 一、功能总览

本项目是一个融合**传统命理**与**Web3经济**的综合性平台，包含以下六大模块：

### 1.1 命理核心

| 功能 | 说明 | 积分消耗 |
|------|------|---------|
| **紫微排盘** | 输入出生年月日时，生成紫微斗数命盘（12宫位、14主星、辅星、四化飞星） | 20 |
| **紫微合盘** | 双盘比对分析，感情/事业兼容性解读 | 50 |
| **每日运势** | 基于命盘的当日运势分析与建议 | 10 |
| **AI解读** | AI流式解读命盘，覆盖13个分析维度 | 10 |
| **AI问答** | 与AI对话，深入探讨命理问题 | 10 |

### 1.2 占卜工具

| 功能 | 说明 | 积分消耗 |
|------|------|---------|
| **测字** | 输入汉字进行字义占卜解读 | 10 |
| **抽签** | 灵签抽取与解签 | 10 |
| **铜钱占卜** | 六爻铜钱起卦占卜 | 10 |

### 1.3 相术分析

| 功能 | 说明 | 积分消耗 |
|------|------|---------|
| **AI面相** | 上传面部照片进行AI面相分析 | 10 |
| **AI手相** | 上传手掌照片进行AI手相分析 | 10 |
| **风水分析** | 环境风水布局AI分析 | 10 |

### 1.4 修行打卡（每日6项）

| 功能 | 说明 | 积分奖励 |
|------|------|---------|
| **诵经打卡** | 早晚课诵经记录，支持经文选择、连续打卡streak | 每项每日首次 +2 |
| **吃斋打卡** | 每日吃斋记录 | 每项每日首次 +2 |
| **打坐打卡** | 冥想打坐时长记录，含呼吸引导 | 每项每日首次 +2 |
| **每日三省** | 每日反思打卡 | 每项每日首次 +2 |
| **太极打卡** | 太极拳练习记录 | 每项每日首次 +2 |
| **积德行善** | 行善记录 | 每项每日首次 +2 |

打卡系统包含**连续streak追踪**和**8级成就系统**：初入道门(1次) → 七日不辍(7天) → 三十日修行(30天) → 百日筑基(100天) → 六根清净(同日6项) → 半百之勤(50次) → 二百精进(200次) → 五百圆满(500次)

### 1.5 修持祈愿

| 功能 | 说明 |
|------|------|
| **祈福** | 向神明祈福，选择祈福对象与神祇 |
| **许愿** | 许下心愿 |
| **忏悔** | 忏悔修行 |
| **长明灯** | 点长明灯祈福 |
| **上香** | 线上上香 |
| **祭祀** | 线上祭祀仪式 |

### 1.6 知识体系

| 功能 | 说明 |
|------|------|
| **古籍库** | 25+部中国传统典籍全文阅读（易经、道德经、论语、孟子、中庸、大学、传习录、金刚经、华严经、楞严经、法华经、心经、了凡四训、庄子、列子、淮南子、骨髓赋、紫微斗数全集/全书等） |
| **知识库** | 14主星 × 12宫位的命理百科，含SEO知识图谱 |
| **古籍搜索** | 全文搜索功能 |

## 二、技术架构

### 2.1 技术栈

| 层 | 技术 |
|---|------|
| **框架** | Next.js 16（App Router） |
| **语言** | TypeScript |
| **样式** | Tailwind CSS + CSS Variables 设计系统 |
| **动画** | Framer Motion |

| **Web3登录** | SIWE（Sign-In with Ethereum）+ ethers + viem |
| **AI** | Anthropic Claude SDK / 火山引擎Ark（流式输出） |
| **图表** | Recharts + 自研SVG可视化 |
| **部署** | Vercel |

| 表 | 用途 |
|---|------|
| `users` | 用户信息（钱包地址、昵称、会员等级、余额、积分） |

| `usage_limits` | 功能使用限额（免费用户3次/功能） |

| `prayer_records` | 祈福/许愿/忏悔记录 |
| `recitation_records` | 诵经打卡记录 |
| `wellness_records` | 修行打卡记录（吃斋/打坐/太极/三省/行善） |
| `feature_stats` | 功能点击热度统计 |

### 2.3 积分体系

| 项目 | 数值 |

| 免费用户限额 | 每功能3次 |

## 三、快速开始

```bash
# 克隆
git clone https://github.com/Renhuai123/ziwei-doushu.git
cd ziwei-doushu

# 安装依赖
npm install

# 配置环境变量（只看排盘可以跳过）
cp .env.example .env.local

# 启动开发服务器
npm run dev
```

本地验证：

```bash
npm run typecheck   # TypeScript 全量类型检查
npm test            # 排盘引擎回归测试
npm run build       # 生产构建
```

## 四、排盘引擎

排盘内核全部在 `lib/ziwei/`。

### 4.1 能做到什么

| 能力 | 说明 |
|------|------|
| **真太阳时校正** | 按出生地经度算时差 + 均时差 |
| **中国夏令时** | 1986–1991 年的夏令时区间自动扣除 |
| **闰月四种口径** | 闰月归前月 / 归后月 / 按日切分 / 按本月，可配置 |
| **晚子时换日** | 23:00–23:59 按次日排盘、00:00–00:59 按本日 |
| **星曜亮度 7 档** | 庙 / 旺 / 得 / 利 / 平 / 不 / 陷 |
| **亮度流派可切换** | 不同流派对辅星亮度判法不一致，做成开关 |
| **四化与飞星** | 生年四化、大限 / 流年四化、飞星自化 |
| **十二神煞** | 本命层按生年支起，流年层改按流年支起 |
| **格局判定** | 1100+ 行规则库（紫府同宫、日月并明、七杀朝斗等） |

### 4.2 核心文件

| 文件 | 说明 |
|------|------|
| `algorithm.ts` | 完整排盘流程 |
| `sihua.ts` | 四化飞星系统 |
| `patterns.ts` | 1100+ 行格局知识库 |
| `true-solar-time.ts` | 真太阳时校正 |
| `dst-cn.ts` | 中国夏令时 |
| `lunar-solar.ts` | 农历/公历互转与闰月边界 |
| `school-config.ts` | 亮度流派配置 |
| `cities.ts` | 中国城市经纬度 |

## 六、管理后台

管理后台位于 `/admin`，仅管理员钱包地址可见。包含5个Tab：

| Tab | 功能 |
|-----|------|
| **用户管理** | 搜索、等级筛选、编辑用户（会员等级/余额/到期日）、个人中心、积分变动明细 |
| **充值记录** | 状态筛选（全部/已确认/待确认）、手动确认/拒绝充值、自动加余额 |
| **积分管理** | 搜索、排序（余额/获得/消耗/变动次数）、功能类型筛选、查看积分明细 |
| **打卡记录** | 6种类型统计卡片、按类型筛选、搜索用户、查看所有打卡详情 |
| **祈福/许愿** | 按类型筛选、搜索用户或内容、查看祈福许愿记录 |

数据统计弹窗包含：
- 5个汇总卡片（总用户/近7天新增/近30天新增/会员比例/近30天充值）
- 3个SVG折线图（用户注册趋势/日活跃用户/打卡次数趋势）
- 各打卡项目柱状图
- 功能使用热度排行
